# Screenshotz privacy policy

_Last updated: November 1, 2026_

Screenshotz is a small screenshot tool for macOS and Windows made by Ashwin Mathias.

**Screenshotz does not collect, store, share or sell any personal information.**

- **Your screenshots stay on your computer.** They're saved in your Documents/screenshots folder and copied to your clipboard. They're never uploaded anywhere.
- **No accounts, analytics, tracking, advertising or crash reporting.**
- **Network use:**
  - The **Windows** app from the Microsoft Store makes no network requests. The Microsoft Store delivers its updates.
  - The **macOS** app checks GitHub (github.com/ashwin-mathias/Screenshots) once a day for a newer version, and downloads it only if you choose to install it. You can turn the check off in the menu. The request contains only the app's version and platform, which GitHub sees as with any web request.
- **Settings** (your shortcut and thumbnail choices) are stored only on your computer.
- **Permissions:** on macOS, Screenshotz asks for Screen Recording permission so it can capture the area you select. It captures only when you ask it to.

Questions: open an issue at https://github.com/ashwin-mathias/Screenshots/issues.
